description: Where to ask for something new in Flex DS.
---

Open an issue on the repository: [github.com/wah-ag/flex-ds/issues](https://github.com/wah-ag/flex-ds/issues).

<p class="flex-notice"><strong>Missing source.</strong> The repo at a70dde1 has no feature-request template or written intake process, so this page names only where to ask.</p>

How a request becomes a component, as the repo describes it:

1. The Designer draws it in Figma and signs off the design.
2. It is built in `src/components/`, documented in Storybook and tested.
3. It ships once it passes QA, and is exported from the package once its release review clears.

A component that needs an icon Lucide does not have, or a token that does not exist, is reported as a gap rather than invented.
