---
title: Report a bug
description: Where to report a problem with Flex DS.
---

Open an issue on the repository: [github.com/wah-ag/flex-ds/issues](https://github.com/wah-ag/flex-ds/issues).

<p class="flex-notice"><strong>Missing source.</strong> The repo at b133157 has no issue template and no written bug-report process, so this page names only where to report.</p>

What helps, from how the repo describes a component:

- The package version (`npm ls @design-rules-the-world/flex-ds`).
- The component, and its props: they are its documented API, and undocumented behaviour is a bug.
- The mode: `data-theme` and `data-scale` on the ancestor.
- The Storybook story that shows it, if one does. Each component page links its stories.
